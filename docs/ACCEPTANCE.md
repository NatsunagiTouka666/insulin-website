# PRD v1.0 验收记录

日期：2026-11-06。当前为私有设计预览，尚未达到正式上线验收。编号沿用已批准 PRD，以下区分实现、实际测试和仍待验收的工作。

2026-11-08 更新：按用户要求增加 Nexio 液态玻璃及弹簧动效，详细实现和验证见 `MOTION.md`。动效版通过 10 项 Node 自动测试、完整动效下 40 组屏宽/路由检查和 8 项 GPU 光学对照。仍不代表物理手机、Safari 或正式域名上线验收。

## 本轮证据

- Astro 7.4.7 静态构建生成 14 个页面；无外部字体、无视频请求、无第三方统计。
- 照片版包含 12 张真实照片、6 组档案及 3 组中英详情页，图片大图及响应式小图共 4,113,152 字节；26 张原图哈希核对无变化。
- 中英 Home、About、Archive 及代表性详情页在 360、390、768、1024、1440 CSS 像素宽共 40 次浏览器检查，均无横向溢出和已加载图片损坏。
- 语言切换后回到根路径，分别正确保留英文与中文选择，无反复跳转。
- 六位成员姓名、乐器与顺序按用户本轮提供的数据录入；英文页保留相同中文姓名。
- 使用自行绘制、明确标注的本机测试 SVG，通过真实 Gallery/Record 组件验证图片展开、多图切换、Esc 关闭、滚动恢复、焦点回到原图片入口；详情页前进后退正常。测试产物位于被忽略的 test-results，不进入部署包。
- 真实四图相册完成点击、按钮切图、键盘右箭头、Esc 关闭测试。修正关闭事件与滚动恢复的时序后，即时检查 body overflow 为空，焦点回到原图片入口。
- 7 项 Node 测试全部通过，覆盖未授权视频、未确认图片、遗漏媒体、翻译不完整、发布前置条件、响应式图片和详情页；所有静态内部链接/脚本路径均解析成功。
- 正式构建检查按预期阻止文案及照片尚未批准的版本。成员信息已确认。
- 浏览器检查最后一轮未记录控制台 error。
- 当前浏览器实际报告 prefers-reduced-motion: reduce；照片版所有内容、导航和大图仍可访问，桌面 1024 像素时视差按预期停用。非减少动态模式下的动效观感仍待验收。

2. 用户审阅中文文案、英文翻译及字标/视觉方向。
3. 建立公开 GitHub 仓库并实际验证 PR 检查、独立预览、受保护正式分支、合并发布与回退。当前 Sites 源码仓库仅用于私有预览，不替代该项要求。
4. 在最终托管账户内核对套餐、免费额度与费用；Pages CMS 尚未接入，GitHub 教程已提供。
5. DNS、HTTPS、主域名重定向、适用合规条件与正式上线授权。
6. 两种实际大陆移动网络、iPhone/Safari/Android 实机、非减少动态模式的动效观感、触摸手势、无脚本回退、长视频与真实媒体恢复演练。
7. 真实用户 Core Web Vitals 第 75 百分位尚无数据，未宣称达到 LCP/INP/CLS 指标；目前本机测试不能替代大陆网络测试。

照片编排未审、翻译未审及发布流程未验证仍属于正式上线阻断项；它们不影响本轮私有设计评审。媒体来源与处理方式见 `MEDIA.md`。
