# insulin.love 部署与恢复

正式域名：`insulin.love`。用户于 2026-11-06 表示 DNS 尚未配置。不得猜测或填入未经托管平台提供的 DNS 地址。

## 当前交付方式

Astro 静态输出到 `dist/`，没有服务端、数据库、账户系统、统计或外部字体。Sites 是本轮私有设计评审环境。正式站点的技术候选仍保留 GitHub + Cloudflare Pages；私有评审部署不等于已完成公开 GitHub 仓库、PR 预览或正式域名配置。

## 正式上线顺序

1. 完成内容核对、成员姓名、照片、中文与英文审核；通过 `pnpm build:release`。
2. 建立公开 GitHub 仓库，推送代码；设置 `main` 保护，要求 Pull Request 和 Verify website 成功，不允许日常直接推送正式分支。
3. 在免费托管方案内完成预览、正式发布与回退实测。Cloudflare Pages 设置构建命令 `pnpm build:release`、输出目录 `dist`、Node 24。PR 预览可覆盖构建命令为 `pnpm build`，仅允许公开素材。
4. 若采用 Cloudflare Pages 的根域名，按照官方文档将该域名作为同一 Cloudflare 账户内的 zone，并在注册商处设置平台实际返回的 nameservers。迁移前完整导出现有 DNS，保留 MX、TXT 和邮件相关记录。
5. 若最终采用 Sites 托管，在网站部署后读取平台返回的根域 A、验证 TXT 及证书验证记录；按返回值在当前 DNS 服务商配置。不要把 `*.chatgpt.site` 的普通 IP 当作根域绑定记录。
6. 正式内容、托管取舍、费用与验收结果供用户确认后，才将网站开放给所有人并绑定正式域名。此轮只做私有评审。
7. 确认 HTTPS 正常、`www` 与根域的主域名策略、404 与语言路径正常；检查适用合规事项与至少两种实际大陆移动网络。

Cloudflare Pages 根域文档：<https://developers.cloudflare.com/pages/configuration/custom-domains/>

## 费用

本地工具和开源依赖未购买服务；本轮未启用对象存储或视频转码。正式托管套餐、当前账户权益及额度需要在最终平台中确认；不要将“可用免费方案”误写成永远零费用。域名有续费成本。任何新增付费服务或按量计费功能都须单独获准。

## 恢复

代码：在 GitHub 对错误合并提交使用 Revert，形成新 PR，检查预览后合并。托管平台可选择上一成功版本回滚。回滚后仍应让仓库与线上版本重新保持一致。

媒体：原始文件至少保留两份独立副本，Git 只保存网页优化版本。恢复演练应从第二份副本复制一张正式照片并构建，验证页面和大图均可打开；尚未收到真实素材，因此该演练待完成。

DNS：变更前导出完整记录；出现故障时按导出记录恢复原 NS 或记录。不要删除无关邮件记录。DNS 生效和 HTTPS 签发必须实际验证后再宣称已上线。
