# 液态玻璃与动效

2026-11-08 按用户要求使用 nexio-liquid-motion skill 适配。保留暖白色系、文案、照片、路由和原有图库功能。

## 实现范围

- 头部保留 About / Archive 两个真实链接，增加弹簧胶囊；语言切换仍为独立链接。
- 五条独立解析弹簧控制位置、归一化速度、压力和 X/Y 缩放，重定向保留速度。正常按压目标 1.11；点击、拖动、键盘操作共用状态。
- WebGL 使用 SDF 轮廓、法线、七波长采样及边缘柔化。按压区域用不透明光学输出替换原文字像素，未复制交互或无障碍导航树。
- 背景来源是导航下方实际显示的受控暖白 Canvas；纹理合成该背景、面板和按实际 DOM 尺寸重绘的文字。它不捕获任意页面 DOM，也不对整张照片进行玻璃折射。
- 普通换页在 Astro ClientRouter 提交后动画化实际正文，页头和页面控件在转场中可继续操作。匹配的档案照片才使用浏览器 View Transition，语言切换按内容锚点恢复阅读位置。链接保留普通多页导航能力。
- 相册在缩略图与大图之间展开和收合。横滑换图、下拉关闭、短拖回弹和键盘操作共用相册状态。换图等原图解码后再过渡，失败时保留当前画面和操作入口。
- 页脚“动效”按钮循环：跟随系统 → 完整 → 减少。只保存本站偏好，不改系统设置。减少动态时关闭非必要位移、回弹和过渡，导航可保留静态按压光学效果。
- 强制色彩、减少透明度、WebGL 不可用或丢失时保留清晰可点击的真实导航；恢复时重建资源。静止时停止动画帧，隐藏页面时清理压力并停帧。

## 来源与许可

`src/lib/liquid/` 保存 optics、解析弹簧、适配后的 NavigationTexture、原正常档 profile、Apache-2.0 许可和 NOTICE。参考为 Nexio Liquid Lab `6aa4ad45e2abf0b268a2eed24e81f154478c8b1a`；原 SDF 片段出处为 NexioSchedule `e67f3b79b9c465789ef7ae192b9c23740e7519da` 的 Apache-2.0 shader。没有分发 AGPL Kotlin 应用代码。

NavigationTexture 已从示例三按钮改为本网站两个锚点和纯文本 span，profile 中原始样本哈希仅用于溯源，不声称适配文件仍与参考哈希相同。这里是二维 Web 显示近似，不是完整光线追踪。

- 自动检查：七波长、RGB 通道归一化、弹簧帧率一致性和反向连续性、单套导航语义、既有内容与链接检查。
- 独立本机 GPU fixture：`node scripts/prepare-motion-qa.mjs`，将 `test-results/liquid-qa/` 通过 HTTP 打开。产物被 Git 忽略，不进入网站部署包。
- 对照固定源、轮廓、材质与光照，分别改变折射、色散和压力，同帧 readback。
- 本次 GPU 对照：白面通道差 0；掩膜外角点 alpha 0；折射改变 2486 个像素；色散改变 700 个像素；按压分色像素 717，静止 56；背景 revision 刷新实际改变像素；上下文丢失与恢复通过。
- 本机完整动效下 40 组视口/路由检查通过，覆盖 360、390、768、1024、1440 CSS 像素；未见横向溢出、已加载图片损坏或 WebGL 初始化失败。
- 已检查拖动反向、拖动切页、Home/End 焦点、Space/Enter 跳转、三档动效开关。连续点击暴露的焦点切换问题已修复，并通过“当前 About → Archive”和“当前 Archive → About”复测；浏览器前进、后退后胶囊与 aria-current 均对应正确。
- 相册打开、Esc 关闭、焦点和滚动恢复通过。快速导航期间浏览器曾报告一次原生 View Transition 被中止，页面导航仍正常完成；不将被取消的原生转场视为切页失败。
