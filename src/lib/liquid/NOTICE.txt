liquid-motion.mjs is the skill's newly written portable adaptation, copied
without modification. It uses Nexio's evidenced spring constants.
optics.mjs adapts shader geometry to WebGL; its magnification, blur, highlight,
pressure response and coordinate handling are new Web approximations.
This demo does not distribute or compile the AGPL-licensed Kotlin application.
The original Nexio application has its own AGPL-3.0 license; this notice does
not relicense that application or the skill's original source assets.

The texture source includes only this demo's procedural Canvas2D scene.
It excludes arbitrary DOM, media and the optical
output. During press/drag, an additional opaque texture redraws only the
existing navigation labels/icons and panel, using their measured DOM geometry.
Its lens replaces covered pixels above the original DOM; it has no semantics
or hit targets.

This revision uses seven wavelength samples (650/610/580/550/500/460/420nm)
with a normalized Cauchy 1/lambda^2 displacement and illustrative RGB response,
rather than the original shader spectral weights. Each channel sums to one.
This is a two-dimensional optical approximation, not physical ray tracing.
CSS fallback provides a readable surface without geometric refraction.

insulin adaptation (2026-11-08): NavigationTexture reads two real anchor links

controlled warm-paper surface, accessibility preference, and animation wiring
